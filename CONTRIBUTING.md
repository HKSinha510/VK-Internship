# Contributing

I'm still learning, so if you spot something that could be better, I'd genuinely like to hear it.

## Ways to help

- **Fix it yourself.** Fork the repo, make your change, and open a pull request. A line or two on what you changed and why helps me learn from it.
- **Open an issue.** If you'd rather just point it out, open a GitHub issue on this repo.
- **Contact me directly.**
