## Dataset
Dataset has been obtained from [kaggle](https://www.kaggle.com/datasets/samartalwar/fast-food-calorie-shock-food-vs-workout-burn). The dataset consists of 8000 records and 23 attributes. Each record is a fast food order with its nutrition, consumer info and burn time. 
The data is Syntheticly generated, which has resulted in similar trend all alone. Sadly, I didn't notice this early while starting the project.
